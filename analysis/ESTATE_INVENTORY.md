# NorthStar Claims — Struts Estate Inventory

Raw inventory of the Struts 1.3.10 estate: action mappings, JSPs, DAO SQL, and
Action → service → DAO call graphs. Generated by static analysis of
`src/main/webapp/WEB-INF` and `src/main/java/com/northstar/claims`.

Module layout (from `web.xml`):

- `config` (default module): `/WEB-INF/struts-config.xml,/WEB-INF/struts-config-claims.xml` → flat `*.do` paths under `/claims/`
- `config/admin`: `/WEB-INF/struts-config-admin.xml` → paths under `/claims/admin/`
- `AuthFilter` guards every `*.do` request; welcome file is `login.do`
- Validator plug-in registered (`validator-rules.xml`, `validation.xml`) in the default module only

`java:comp/env/jdbc/ClaimsDB` per checkout, falls back to

## 4. Call graph: Action → services → DAO → tables

**Key structural finding:** the singleton service layer (`ClaimManager`,
`PolicyManager`, `SettlementService`) is referenced by **no Action class**.
Actions either instantiate DAOs directly (`new XxxDAO()`) or run raw JDBC via
`ClaimsActionSupport`. The only singleton actually on a request path is
`SettlementCalculator`.

```
LoginAction              → (no DB; hard-coded credential check in Java)
HomeAction               → (no DB)
LogoutAction             → (no DB; session invalidate)
ReportIndexAction        → (no DB)
IntakeNewAction          → (no DB)
IntakeConfirmAction      → (no DB; echoes claimId param)
web.admin.ReferenceDataAction → (no DB; hard-coded loss types)

PolicySearchAction       → new PolicyDAO().findByLine(line)                     → POLICY
PolicyListAction         → new PolicyDAO().findAll()                            → POLICY
PolicyViewAction         → new PolicyDAO().findById(policyId)                   → POLICY
PolicyCoveragesAction    → new PolicyDAO().findById(policyId)                   → POLICY
PolicyCoverageDetailAction → new PolicyDAO().findById(id)                       → POLICY
PolicyInsuredPartyAction → new PolicyDAO().findById(id)                         → POLICY
PolicyRenewalAction      → new PolicyDAO().findById(id) [fallback findById(9001)] → POLICY
PremiumDetailAction      → new PolicyDAO().findAll()                            → POLICY

IntakeSubmitAction       → ClaimsActionSupport.nextId("CLAIM")                  → CLAIM
                         → raw JDBC insert into CLAIM                           → CLAIM

WorkbenchListAction      → new ClaimDAO().findByStatus("OPEN")                  → CLAIM

                         → findClaim → ClaimDAO.findById                        → CLAIM
```
